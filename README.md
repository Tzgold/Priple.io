# Priple

Crypto trading intelligence — wallets, market screener, and social signals in one surface.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Geist font, Lucide icons
- Mock data for the app shell (no backend yet)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Path | Description |
|------|-------------|
| `/` | Marketing landing |
| `/login` `/signup` | Auth UI (stubs → `/app`) |
| `/app` | Overview shell |
| `/app/wallets` | Wallets stub |
| `/app/screener` | Screener stub |

## Note

Outputs are informational only — not investment advice.
